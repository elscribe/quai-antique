# Conception des données — Quai Antique

## Provenance des documents

Les documents de conception ont été copiés dans le dépôt applicatif Quai Antique depuis le dépôt local du Dossier professionnel, branche `exemple-04-base-de-donnees`, commit `5995b7fdb27f9d79ce8409fc676cb3045c9c71f6`.

Le dépôt du Dossier professionnel est la source d’origine des preuves et n’a pas été modifié. Cette copie sert de base de travail au projet complet Quai Antique.

## Fichiers repris

- `../conception/Quai Antique CDC.pdf` : cahier des charges client.
- `../conception/brief-client.md` : synthèse du brief.
- `../conception/analyse-besoin.md` : besoins et contenus repérés.
- `../conception/parcours-utilisateur.md` : parcours visiteur, client et administrateur.

## État de la modélisation

Le fichier Draw.io est une conception préalable, pas une preuve qu’une base de données est créée. Le MCD/MLD doivent encore être confrontés au cahier des charges et au cours Doctrine avant la création des entités et des migrations.

Voir [`rapport-ecarts-cours.md`](rapport-ecarts-cours.md) pour le relevé initial des écarts à examiner.
