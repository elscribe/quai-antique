# Brief client

## Source du brief

CDC Quai Antique fourni par l'utilisateur.

- restaurant Quai Antique ;
- chef Arnaud Michant ;
- restaurant situé à Chambéry ;
- application web vitrine ;

- affichage de la carte et des menus ;
- réservation de table ;
- inscription et connexion client ;
- espace client ;
- espace d'administration.

## Contexte du projet

Le projet concerne un restaurant qui souhaite présenter son établissement et
permettre aux visiteurs de préparer une réservation en ligne.

Le chef veut transmettre l'univers culinaire du restaurant et mettre en avant
les produits de Savoie. Le site doit donner envie de venir au restaurant, tout
en facilitant le parcours de réservation.

## Objectifs du site ou de l'application

Objectifs retenus pour démarrer :

- présenter le restaurant ;
- mettre en avant les produits et l'ambiance ;
- donner accès à la galerie ;
- afficher la carte complète ;
- permettre la réservation d'une table ;
- permettre la création d'un compte client ;
- prévoir l'administration des informations du restaurant.

## Public visé

Public principal :

- visiteurs qui veulent découvrir le restaurant ;
- clients qui souhaitent réserver une table ;
- administrateur chargé de gérer les contenus du site.

L'interface doit rester lisible sur mobile, car une réservation peut être faite
rapidement depuis un téléphone.

## Pages ou écrans attendus

Première liste :

## Contraintes

Contraintes retenues pour cette étape :

- responsive desktop et mobile ;
- navigation simple ;
- texte lisible ;
- actions principales visibles rapidement ;
- disponibilité des places sans rechargement de page ;
- réservation par créneaux de 15 minutes ;
- réservation limitée par le nombre maximum de convives ;
- réservation validée uniquement par un utilisateur connecté ;
- structure prête pour les futures données API.
